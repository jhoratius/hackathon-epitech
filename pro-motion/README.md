## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This website allows you to manage your tasks with a due date, duration and priority levels.

In order to put yourself a pressure, when you get a certain amount of tasks that has near due dates,
you're entering into "Rush Mode", it restrains you to only pick the important tasks, so first the priority 1, then 2, etc..
You also have access to a calendar of your tasks.

Put tasks in this format :
"due date today buy milk takes about 1h priority 3"
